> **Last reviewed:** 2026-10-10 · **Last updated:** 2026-10-30 · **Change:** minor (M5: supersampled exports avoid redundant opaque knockout layers; File formats: `.ai`/EPS import fidelity from a user's file audit; scores unchanged) · **Target:** Adobe Illustrator 2026 (30.x)

## Alpha gate

The core-workflow gate: what a typical professional does with
Illustrator every day, checked end to end on the main platform (macOS) with save and reopen in the native
`.clerdovector` format (lossless, property-tested round trips in `crates/format/tests/prop_format.rs`).
Checked 2026-10-10 from the code, tests and open issues; no workflow fails, so ClerdoVector passes and stays alpha.

## Current focus

1. **Interaction-fidelity pass** (G1) by tool, from [ui-parity.md](ui-parity.md): Pen and Curvature, Direct
   Selection, smart guides and snapping first. 60–90 h, parallel by tool.
2. **`.ai` files from real users** (G9): layer structure (#951), guides (#779). 10–20 h.
3. **Launch and stability** (G10): the Windows and Linux start-up reports. 20–35 h.
4. **Core-tool bugs** (G11): SVG units reverting to points (#864) and a Transform effect in a fill's or stroke's own effects (#885). Shape Builder regions (#937), Asset Export ghost borders (#983 / #1037) and the stalling bezier drag preview (#834) are fixed. 8–15 h.
5. **Raster effects** (G2) alongside: the Effect Gallery's filter thumbnails and in-dialog preview area (the gallery and every Photoshop-style filter are in), 1–2 h.

## Next

- **Then:** advanced type (G4) and the Illustrator 2026 additions (G13), then 3D (G3), each with a plan in
  `plan/` before coding.
- **Alongside:** close the 28 stubbed menu items; run `clerdovector-cli perf` on an idle machine and fix any
  budget missed (G15).
- **Beta:** G1, G9, G10, G11, G12, the corpus part of G8, type core, macOS pen pressure and the perf budgets
  (~170–270 h one agent, ~50–80 h with 4–6 agents).
- **1.0:** feature parity plus the fidelity pass, hardening and packaging for all three desktop OSes and the web.

## Highlighted-text Eyedropper (2026-10-21)

Type/Eyedropper switches preserve highlighted characters; sampling changes only their enabled
font/paint attributes. Enabled non-neutral source or target object transparency is refused
atomically; disable Transparency to preserve object transparency while sampling the range.
`tests/eyedropper.rs` covers ranges, Unicode, history and transparency; tool tests cover brush-key
sampling coexistence. Scores and estimates unchanged. See [development.md](development.md#highlighted-text-eyedropper-2026-10-21).

## Drag artwork between document tabs (2026-10-22)

Selection drags activate another visible document tab after 400 ms, then copy editable artwork
on canvas release with the original grab point. Source and clipboard preservation, resource
rendering, swatch conflicts, cancellation, rotated/zoomed views and target Undo/Redo have regression
coverage (`tests_document_drag`, `tests_clipboard`). Overflow-menu and cross-window drag remain
separate. Scores and hours unchanged. [Behavior and command details](development.md#drag-artwork-between-document-tabs-2026-10-22).

## EPS Save evidence (2026-10-26)
Ordinary Save and Save As keep EPS as EPS, with the chosen page frame, transparent margins and the complete editable ClerdoVector document. Existing import-loss confirmation and transparency warnings remain; the Save TIFF preview is capped at 1024 pixels, while Export retains 2048. See [file-format-parity.md](file-format-parity.md#eps-save-and-source-protection) for limits and regression evidence. This narrows G9 save-back workflow coverage; native Illustrator editing-data fidelity, parity scores and hour estimates are unchanged.
