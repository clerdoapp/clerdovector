ClerdoVector portable mode

While this file sits next to clerdovector.exe, ClerdoVector keeps its preferences, swatch and
graphic style libraries, added fonts, crash-recovery files and logs in the ClerdoVectorData folder
beside it, and writes nothing to %APPDATA%. Copy the whole folder to move ClerdoVector with its
settings. The first time ClerdoVectorData is created, any settings already in
%APPDATA%\ClerdoVector are copied into it; the originals are left where they were.

Keep this folder somewhere only you can write to: whoever can write here decides your settings,
including the plug-ins and fonts folders ClerdoVector loads from, and the Data Recovery copies of
your unsaved documents are kept here too.

Delete this file to use the normal per-user settings folder (%APPDATA%\ClerdoVector) instead.
If ClerdoVectorData can't be written (for example on a read-only drive), ClerdoVector logs a
warning and uses %APPDATA%\ClerdoVector instead.
